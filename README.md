# Diese Docs

Central repository for reusable playbooks, templates, guardrails, and operating manuals.

This repo exists so project rules do not get trapped inside individual app repositories or old chat threads.

## What Belongs Here

- Repo documentation templates
- AI workflow guardrails
- README standards
- Agent instruction templates
- MVP, roadmap, task, and decision templates
- Client website discovery and design templates
- Business operating manuals
- Prompt frameworks worth reusing

## Current Structure

- client-websites/custom-authored-website-template.md
- repo-guardrails/agents-template.md
- repo-guardrails/ai-workflow-guardrails.md
- repo-guardrails/project-docs-kit.md
- repo-guardrails/readme-template.md

## Operating Rule

Project repos can keep project-specific docs. This repo keeps the generic source templates.

When a project doc becomes reusable across multiple repos, promote a cleaned-up version here.
