# Monetization Readiness

Use this before attempting to monetize a project.

The goal is to determine whether the product is actually ready for paid users.

---

# Problem Validation

- [ ] Product solves a meaningful problem
- [ ] Users voluntarily return
- [ ] Users express frustration when unavailable
- [ ] Product creates measurable value

---

# User Readiness

- [ ] Target audience identified
- [ ] User workflow validated
- [ ] Customer objections understood
- [ ] Support expectations understood

---

# Product Readiness

- [ ] Core workflow stable
- [ ] Major bugs understood
- [ ] Operational burden manageable
- [ ] Product can survive light real-world usage

---

# Operational Readiness

- [ ] Billing strategy chosen
- [ ] Pricing logic exists
- [ ] Refund/support expectations understood
- [ ] Terms/privacy requirements considered
- [ ] Maintenance expectations understood

---

# Technical Readiness

- [ ] Deployments are reasonably stable
- [ ] Rollback path exists
- [ ] Logging exists
- [ ] Failure modes understood
- [ ] Dangerous workflows identified
