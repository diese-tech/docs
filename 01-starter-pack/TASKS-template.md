# Usage Rules

- Keep tasks actionable.
- Prefer small reviewable units.
- Move tasks instead of duplicating them.
- Delete stale work.
- Separate current work from future ideas.
- Do not let this become a backlog graveyard.

# Task Philosophy

A good task system should:

- reduce ambiguity
- reduce context-switching
- reduce forgotten work
- expose blockers early
- preserve implementation momentum

The task list exists to move work forward, not to perform productivity theater.
