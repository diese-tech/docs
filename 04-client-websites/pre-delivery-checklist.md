# Website Pre-Delivery Checklist

Use this before handing a website to a client.

The goal is to reduce broken links, missing content, fake claims, and avoidable support requests.

---

# Content Review

- [ ] Business name is correct
- [ ] Contact information is correct
- [ ] Pricing is correct
- [ ] Business hours are correct
- [ ] Policies/disclaimers are included if needed
- [ ] Testimonials are approved
- [ ] No placeholder copy remains
- [ ] No fake claims exist

---

# Visual Review

- [ ] Mobile layout reviewed
- [ ] Desktop layout reviewed
- [ ] Images load correctly
- [ ] Typography is consistent
- [ ] Spacing feels intentional
- [ ] Animations are not excessive
- [ ] Site feels aligned with brand identity

---

# Functional Review

- [ ] Forms submit correctly
- [ ] Form notifications work
- [ ] Buttons link correctly
- [ ] Navigation works
- [ ] External links work
- [ ] Booking/payment links work
- [ ] Social links work

---

# Technical Review

- [ ] No obvious console errors
- [ ] Metadata configured
- [ ] Open Graph configured
- [ ] Favicon exists
- [ ] Sitemap exists if applicable
- [ ] Analytics configured
- [ ] Performance reviewed

---

# Operational Review

- [ ] Client has required account access
- [ ] Hosting ownership confirmed
- [ ] Domain ownership confirmed
- [ ] Environment variables documented
- [ ] Maintenance expectations explained

---

# Final Questions

## Could this website belong to another company with only the logo swapped?

If yes, the site still feels generic.

[Answer]

---

# Final Rule

A website is not complete just because it looks good.

It should:
- work reliably
- support the business goal
- reflect the brand identity
- reduce confusion
- create trust
