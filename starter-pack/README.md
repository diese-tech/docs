# Starter Pack

Use this folder when starting a new project repo.

The goal is to avoid blank-repo syndrome by starting every project with scope, guardrails, decisions, and operating rules already in place.

## Default Files for New Projects

- README.md
- AGENTS.md
- MVP.md
- ROADMAP.md
- TASKS.md
- DECISIONS.md
- docs/AI_WORKFLOW_GUARDRAILS.md

## How to Use

1. Copy the files from this folder into the new repo.
2. Replace bracketed placeholders with project-specific details.
3. Keep scope intentionally small.
4. Link back to diese-tech/docs as the source of reusable standards.
5. Update docs as decisions change.

## Default Rule

Every new project should begin with documentation before implementation.

Not because docs are cute.

Because undocumented projects become expensive to understand later.
