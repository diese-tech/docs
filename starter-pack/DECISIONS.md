# Decisions Log Template

Record important architectural, operational, and product decisions.

This document exists to preserve reasoning over time.

Without it, projects slowly become:
- tribal knowledge
- forgotten tradeoffs
- repeated debates
- accidental regressions

# Decision Rules

Log decisions when:

- architecture changes
- product direction changes
- persistence/storage changes
- auth/billing behavior changes
- deployment strategy changes
- operational workflows change
- large dependencies are introduced
- tradeoffs are intentionally accepted

Do not log trivial formatting or copy changes.
