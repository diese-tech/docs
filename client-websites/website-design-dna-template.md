# 10. Anti-Generic Rules

Avoid:

- Generic SaaS layouts
- Random gradients
- Endless rounded cards
- Stock icon grids
- Unmodified UI library styling
- Over-animation
- Generic hero sections
- Vague AI copy

Before launch ask:

Could this site belong to another business with only the logo swapped?

If yes, the site is not finished.

---

# 11. Final Standard

A successful website should feel authored.

The client should be able to say:

"That feels like us."
