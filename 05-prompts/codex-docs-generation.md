# Codex Docs Generation Prompt

```text
Review the repository and generate missing operational documentation.

Goal:
Create practical documentation that helps future maintainers, operators, collaborators, and clients understand the system.

Prioritize:
- clarity
- maintainability
- operational usefulness
- architecture understanding
- workflow explanation

Do NOT:
- invent features
- rewrite code
- propose architecture changes unless explicitly asked
- generate vague filler documentation

Potential outputs:
- README improvements
- OPERATIONS.md
- CODEBASE_WALKTHROUGH.md
- architecture map
- risky areas audit
- release checklist
- troubleshooting notes

Rules:
- Reference actual files and workflows.
- Explain systems in plain English first.
- Identify uncertainty instead of guessing.
- Focus on real operational value.
- Avoid documentation theater.
```
